# 🎓 EduConnect University — Portail Académique & Gouvernance

Portail académique moderne et dynamique développé avec **Symfony & Twig**, conçu pour offrir une expérience utilisateur immersive (Glassmorphism, thèmes sombres et animations 3D) aux étudiants et professeurs.

---

## ✨ Fonctionnalités Principales
- 🎨 **Interface Modern Glassmorphism** : Thème sombre sophistiqué avec effets de flou et animations CSS3 fluides.
- 📚 **Bibliothèque Numérique interactive** : Carrousel d'ouvrages classés par département avec un effet d'onde boursière animé.
- 🏫 **Gestion des Départements** : Navigation dynamique entre les départements scientifiques (Mathématiques, Informatique & IA, Biologie, Physique-Chimie, Géologie) et leurs sous-filières (Master Info & Télécom, DSI / Big Data, SMA, SMI, etc.).
- 🎓 **Accès Direct aux Cycles** : Liens rapides vers les Licences, Licences d'Excellence, Masters, Masters d'Excellence et Doctorats.
- 💼 **Offres de Stages & PFE** : Passerelle dédiée aux opportunités professionnelles avec les entreprises partenaires.
- 🎥 **Salles Virtuelles Live** : Espace de visioconférence et collaboration inspiré des plateformes modernes avec des accès distincts Professeur et Étudiant.
- 🔐 **Authentification Sécurisée** : Espace de connexion unifié par Numéro de CNI et Code Apogée.

---

## 🛠️ Stack Technique
- **Backend** : PHP / Symfony
- **Frontend** : Twig, CSS3 (Glassmorphism, Keyframes Animations), JavaScript Vanilla
- **Outils** : Git / GitHub
